# Wortliste der Suite

Eine Sache heißt in jedem Modul gleich. Wer in zwei Modulen arbeitet, soll nichts doppelt lernen
(IDA-395, aus dem UX-Durchgang vom 10.11.2026). Gilt für alles, was auf dem Bildschirm steht: Knöpfe,
Überschriften, Spaltenköpfe, Meldungen, Menüpunkte. Quelltext, Tabellen- und Feldnamen bleiben, wie sie
sind.

Wer ein neues Wort für etwas braucht, das hier schon steht, nimmt das Wort von hier. Wer etwas
Neues benennt, das in einem zweiten Modul auftaucht, trägt es hier ein.

## Anrede

- **„du"** auf allem, was Helferinnen und Helfer benutzen: Helferwege per Code oder QR, Telefonseiten,
  Feedback-Abende, Kommunikationspläne, Drohnentraining, Gemeinschaft, Bar-Anfrage, Verwaltung.
- **„Sie"** nur im Modul **Dateien** auf den öffentlichen Seiten (Freigabe- und Abgabelinks). Sie gehen
  auch an Außenstehende: Behörden, andere Organisationen, Veranstalter. Das ist eine bewusste Ausnahme.
- Innerhalb einer Seite nie gemischt. Eine Meldung, die auf beiden Arten von Seiten erscheinen kann,
  vermeidet die Anrede („Link abgelaufen.").

## Helferzugang ohne Anmeldung

Lagerbuch, Verpflegungslager und Funkgeräte lassen Helfer ohne Konto hinein, über einen Code auf
Etikett, Aufsteller, Kärtchen oder QR.

| Wo | Wort |
|---|---|
| Die Sache | **Zugangscode**, im Zusammenhang kurz **Code** |
| Verwaltungsseite und Menüpunkt | **Zugangscodes** |
| Eingabefeld an der Tür | Beschriftung und Platzhalter **Zugangscode** |
| Kopfzeile der Helferansicht | **Zugangscode · \<Bezeichnung\>** (nie „Token", nie der Code selbst) |
| Spalten der Verwaltung, in dieser Reihenfolge | **Bezeichnung** · **Code** (nur wo er abgetippt wird) · **Zustand** · **Gültig bis** (nur wo er abläuft) · **Zuletzt benutzt** · Aktionen |
| Zustände | **aktiv**, **abgelaufen**, **gesperrt** |
| Aktionen | **Zugangscode anlegen** (Knopf oben rechts), **QR zeigen**, **Link kopieren**, **Sperren**, **Entsperren** |

Nicht: „Helfer-Link", „Zugang" als Name für das Ding, „Token", „Zugangs-Code" mit Bindestrich, „Code
vom Etikett", „Code vom Aufsteller", „wieder freigeben".

Die Gerätewartung braucht keinen Code: der QR am Gerät führt direkt auf die Geräteseite.

## Fristen

| Wo | Wort |
|---|---|
| Die Sammlung aller Fristen (Portal, Modulübersichten) | **Was steht an** |
| Einzelne Frist | **überfällig**, **fällig** (heute), **bald fällig** |
| Ablaufdatum von Sanitäts- und Verbrauchsmaterial | **Verfall** (Spalte „Verfall"), ohne Datum: **ohne Verfall** |
| Ablaufdatum von Lebensmitteln | **MHD** (Mindesthaltbarkeitsdatum, im Verpflegungslager üblich) |
| Was zuerst abläuft | **Zuerst ablaufende** (nicht „FEFO") |

Verfall und MHD sind fachlich verschieden und bleiben getrennt; „Kritische Artikel" wird zu „Was steht an".

## Zustände eines Geräts oder Fahrzeugs

| Zustand | Bedeutung |
|---|---|
| **einsatzbereit** | darf raus, nichts offen |
| **einsatzbereit mit Mangel** | darf raus, ein Mangel ist gemeldet |
| **nicht einsatzbereit** | darf nicht raus |
| **außer Dienst** | vorübergehend aus dem Bestand genommen (Gegenstück: **im Dienst**, nicht „aktiv") |
| **ausgemustert** | endgültig weg, bleibt als Nachweis |

## Ausleihen

| Wo | Wort |
|---|---|
| Gerät liegt bereit | **verfügbar** (nicht „frei") |
| Gerät ist unterwegs | **ausgeliehen** (nicht „vergeben") |
| Aktionen | **Ausleihen**, **Zurückgeben** |
| Wer es hat | **ausgeliehen von \<Name oder Rufname\>** |

## „Freigeben"

Je Modul höchstens **eine** Bedeutung. Wo etwas anderes passiert, steht das Verb, das passiert:

| Modul | Wort |
|---|---|
| Feedback: einen Abend für Rückmeldungen öffnen | **Umfrage starten** |
| Kummerkasten: Antwort an die meldende Person | **Antwort senden** |
| Aufgaben: fertig gemeldete Arbeit abnehmen | **Freigeben** (die eine Bedeutung im Modul) |
| Helfer: für das Einsatztagebuch | **Bereitstellen** / **nicht mehr bereitstellen** |
| Dateien: Link für andere | **Freigabe** (das Ding), **Freigabe anlegen** |
| Zugangscodes | **Entsperren** |

## Technikwörter

Nicht auf dem Bildschirm. Ersatz:

| Nicht | Sondern |
|---|---|
| Slug | **Kennung** (oder aus dem Namen ableiten und nicht zeigen) |
| Presets | **Schnellzugriffe** |
| Magic-Link | **Anmeldelink** |
| Token | **Zugangscode** |
| FEFO | **Zuerst ablaufende** |
| Pocket-ID-Kennung | **Konto-Kennung** |
| Soll-Minuten | **Zeit pro Tag** (mit Einheit im Feld, z. B. Stunden) |
| Volume, Bytes | **Speicher**, in MB/GB gerechnet |
| Trockenlauf | **Vorschau** |
| KEK, Umgebungsvariablen | aus der Oberfläche heraus; die Meldung sagt, was nicht geht, und an wen man sich wendet |
| Anker-Abweichungen | **Abweichungen** mit dem, was abweicht |
